# Atlas Invest assignment
This project includes a BE app for processing loans.

## How to run the app
Use makefile commands to run the app

**Build the containers**
```bash
   make build
```

**Start the containers**
```bash
   make up
```

**See the logs**
```bash
   make logs
```


**Stop the containers**
```bash
   make down
```

**Run migrations**
```bash
   make migrate
```

**Run tests**
```bash
   make test
```
